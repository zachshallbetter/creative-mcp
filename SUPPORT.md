# Support

Creative MCP has a solo maintainer, so support is best-effort with no SLA.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/creative-mcp/issues/new/choose).
  For a problem with a tool's own code, use that tool's repository: [adobe-mcp](https://github.com/zachshallbetter/adobe-mcp)
  or [blender-mcp-rs](https://github.com/zachshallbetter/blender-mcp-rs). `creative-mcp doctor` reports what the
  installer found and the command that fixes each problem; include its output in a bug report.
- **Security reports:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Versions:** installer releases are tagged `cli-vX.Y.Z`.
